# 産業用センサーモニター

## 概要

温度、電圧、圧力の3つの値を入力し、正常範囲に入っているか確認するC言語のプログラムです。
それぞれのセンサーの状態と、最後に全体の状態を表示します。
実際の機械を動かすものではありません。

## 機能

- 温度、電圧、圧力を入力できる
- 各センサーが正常か警告かを表示する
- 範囲外の値には `WARNING` を表示する
- 最後に `ALL SENSORS NORMAL` または `WARNING` を表示する
- 数値以外が入力されたら、エラーを表示して終了する

## センサーの範囲

| センサー | 単位 | 正常範囲 |
|---|---|---|
| 温度 | °C | 0〜80 |
| 電圧 | V | 200〜240 |
| 圧力 | bar | 2〜8 |

境界値（0、80、200、240、2、8）は正常です。

## 必要なもの

- C言語
- GCC（MinGW）
- Visual Studio Code
- Windows（PowerShell）

## コンパイルと実行

GCCが必要です。VS Codeのターミナルで、`main.c` があるフォルダを開いて実行します。

```powershell
gcc -Wall -Wextra -Wpedantic main.c -o sensor_monitor.exe
```

コンパイルが成功すると、`sensor_monitor.exe` ができます。
次に、プログラムを実行します。

```powershell
.\sensor_monitor.exe
```

入力例:

```text
Temperature (C): 25
Voltage (V): 220
Pressure (bar): 5
```
