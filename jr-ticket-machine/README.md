# JR券売機シミュレーター

## 概要

駅を選んで切符を買う流れを、ターミナルで試せるC言語のプログラムです。
大人と子供の人数を選び、現金またはICカードで支払います。
実際のJRの券売機ではありません。

## 機能

- 4つの駅から行き先を選べる
- 大人と子供の人数を入力できる（子供は大人の半額）
- 現金で支払うと、お釣りを表示する
- ICカードで支払うと、残高を表示する
- 駅番号、人数、支払い方法、金額が正しくないときはエラーで終了する
- 大人と子供はそれぞれ10人まで

## 運賃

| 駅 | 大人 | 子供 |
|---|---:|---:|
| Tokyo | 150円 | 75円 |
| Shinjuku | 210円 | 105円 |
| Shibuya | 210円 | 105円 |
| Akihabara | 150円 | 75円 |

ICカードの最初の残高は2000円です。

## 必要なもの

- C言語
- GCC（MinGW）
- Visual Studio Code
- Windows（PowerShell）

## コンパイルと実行

```powershell
gcc -Wall -Wextra -Wpedantic jr_ticket.c -o jr_ticket.exe
```

```powershell
.\jr_ticket.exe
```

## 使い方

1. 行き先の駅番号を入力します。
2. 大人と子供の人数を入力します。
3. 支払い方法を選びます（1: 現金、2: ICカード）。
4. 現金の場合は、入れる金額を入力します。

## 制限

- 実際のJRの券売機ではありません。
- 運賃はサンプルです。
- ICカードの残高はプログラムを終了するとリセットされます。
- 切符の印刷は画面表示だけです。
