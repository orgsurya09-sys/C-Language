# スマート電力量計シミュレーター

## 概要

電気の使用量（kWh）を入力すると、電気料金の目安を計算するC言語のプログラムです。
使用量が正常か、多いかを判定して表示します。
実際の電力量計ではありません。

## 機能

- 電気の使用量を入力できる
- 1kWhあたり30円で料金を計算する
- 使用量、料金単価、推定料金を表示する
- 0〜300kWhは `NORMAL`、300kWhより多い場合は `HIGH CONSUMPTION` と表示する
- マイナスの値や数値以外の入力はエラーにして終了する

## 計算方法

```text
推定料金 = 使用量（kWh） × 30円
```

例: 250kWh × 30円 = 7500円

## 料金と警告の基準

| 項目 | 値 |
|---|---|
| 電気料金 | 1kWhあたり30円 |
| 正常な使用量 | 0〜300kWh |
| 使用量が多い場合 | 300kWhより大きい |

300kWhは正常です。

## 必要なもの

- C言語
- GCC（MinGW）
- Visual Studio Code
- Windows（PowerShell）

## コンパイルと実行

GCCが必要です。VS Codeのターミナルで、`main.c` があるフォルダを開いて実行します。

```powershell
gcc -Wall -Wextra -Wpedantic main.c -o smart_meter.exe
```

```powershell
.\smart_meter.exe
```
