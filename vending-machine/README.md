# 自動販売機シミュレーター

## 概要

これは、日本の自動販売機をシミュレーションするC言語のプログラムです。
飲み物を選んで金額を入力すると、購入できたかどうかとお釣りを表示します。
実際の自動販売機のハードウェアを動かすものではありません。

## 使用したもの

- C言語
- GCC（MinGW）
- Visual Studio Code
- Windows（PowerShell）

## できること

- 3種類の飲み物から選べる
  - Water：100円
  - Green Tea：120円
  - Coffee：150円
- 金額を入力して購入できる
- お釣りを計算して表示する
- 間違った飲み物番号を受け付けない
- 文字、空の入力、マイナスの金額、0円、大きすぎる金額を受け付けない
- お金が足りないときは、不足している金額を表示する
- `0` を入力すると終了する
- 購入したあとも、続けて購入できる
- 入力が終了したとき（EOF）も、止まらずに終了する

## 実行方法

GCCが必要です。プロジェクトのフォルダで、次のコマンドを実行します。

```powershell
gcc -Wall -Wextra -Wpedantic main.c -o vending_machine.exe
```

コンパイルが成功すると、`vending_machine.exe` ができます。
次に、プログラムを実行します。

```powershell
.\vending_machine.exe
```

日本語が文字化けするときは、先に `chcp 65001` を実行してください。

## 確認したこと

テストの内容は [docs/test_cases.md](docs/test_cases.md) にまとめています。
次の17件を実行し、すべて合格しました。

- 正常な購入（ちょうどの金額、お釣りあり）
- 不正な飲み物番号
- 文字入力と空入力
- マイナスの金額、0円、大きすぎる金額
- 金額不足
- `0` で終了
- 入力終了（EOF）

テストは、入力ファイルをリダイレクトして実行しました。
自動テストのフレームワークは使っていません。
